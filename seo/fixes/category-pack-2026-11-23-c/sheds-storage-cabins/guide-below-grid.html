How to choose a wooden storage shed

Size by what you store. For hand tools and garden items, the small sheds of 2–5 m² inside suit, such as Lulu-1 2.4 x 1.2, Madrid 2.14 x 2.15, Bedford, Edith or Ariadne 2.2 x 2.2 and Lyric 3 x 2. For bikes and a mower, look at 6–10 m², such as Alva 3 x 3, Toronto 3 x 3, Osaka 3.2 x 3.2 or Genova 3.8 x 3. For a workbench as well, Alva 4 x 4 (14 m²) and Lynx 5 x 4 (17.8 m²) are the largest.

Door. Measure your widest item first. The listings show single doors, double doors and fully glazed double doors; Emma 3 x 3 and 4 x 3 list a quadruple all-glass door. Door type is on each product page.

Windows and light. Most sheds list single glazing, which is enough for storage. Edith 3 x 3 and Edith 3 x 2 with 28 mm walls list double glazing.

One room or two. Atlanta 3.56 x 2.2, Elyra 3 x 4.4, Megy 2.6 x 4.1 and Rita 3 x 4.4 are split into two rooms, useful to keep tools apart from bikes or firewood.

Terrace. Seven models add a covered terrace, from 1.4 m² on Atlanta to 12.3 m² on Eric and Rapture 3.3 x 7.36.

28 or 44 mm. For storage, 28 mm walls are enough. For a hobby room, the 44 mm Premium sheds are thicker; compare them in our wall thickness guide.

Base and planning

A shed needs a flat, firm, level base such as paving slabs, a gravel bed with a timber frame, or ground screws. Treat the timber after assembly. Check size and boundary rules in our UK planning permission guide.
